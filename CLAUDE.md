## Agent skills

### Issue tracker

Issues e specs deste repositório vivem no GitHub Issues (`LAMIT-UCSAL/Lamitrack-backend`), via `gh` CLI. Ver `docs/agents/issue-tracker.md`.

### Triage labels

Vocabulário padrão das cinco triagens canônicas (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`), sem mapeamento — os nomes no repo são os mesmos das skills. Ver `docs/agents/triage-labels.md`.

### Domain docs

Single-context: um `CONTEXT.md` + `docs/adr/` na raiz. Ver `docs/agents/domain.md`.
